    Add something the app missed

    You just remembered the thing. Get it onto the list before it evaporates.

    The gist

    • Tap the + circle at the bottom right. The New Item sheet opens: type the name, choose a Section (it starts blank, because the app won't guess), and tap ✓.
    • Adding several to one section? Press return or tap Quick Add instead of ✓. The item lands and the sheet stays open for the next one.
    • For the quick field, drag the + instead, and let go where the item belongs. Every section's own + Add Item row opens the same field. It searches your library as you type — pick a match and you get its notes, quantity rules and charging info for free.
    • No match? Tap Create "…" and it's added as a one-off for this trip.
    • Only return, a suggestion or the top row adds. Tapping ✕ or anywhere else closes the field and drops what you typed.

    Do it

    1. Tap the + circle — the round button beside the tab bar at the bottom right.

    The New Item sheet opens, titled for the list you're on: "New Item on Pack List". Type the name, then choose a Section. It starts blank on purpose: a tap doesn't say where the item belongs, so the app asks rather than guessing. A note, a quantity and its rule are there too, if you want them now.

    2. Add it.

    Tap ✓ to add the item and close the sheet. To add several to the same section, press return or tap Quick Add, which names the section once you've chosen it ("Quick Add to 🧴 Toiletries"). The item lands, and the sheet stays open with the section kept, ready for the next name.

    The quick field

    Drag the + and let go where the item belongs, or tap the + Add Item row at the foot of any section. Either one opens a field right in the list, in the gap the item will occupy. There's no sheet.

    Start typing. After two letters, suggestions appear:

    • From your library — items you already have definitions for. Picking one brings its default note, its quantity rule, and whether it needs charging.
    • In this trip — something you've already added elsewhere on this trip, captioned with where it came from (for example "from Beach Day"). Picking this links the two rows: they count as the same object, so checking one checks the other.

    The top row is what return does: the library item when what you've typed matches one, or Create "whatever you typed" when nothing does.

    Press return. The item lands and the field stays open and focused for the next one. That's deliberate: the expensive part of remembering isn't typing, it's the gap between remembering and recording.

    Done? Tap the ✕, or anywhere else. The field closes. Anything you typed but didn't add is dropped, not saved. Scrolling the list is the one thing that keeps it.

    Quantities: type them inline

    Both of these work:

    3 shirts
shirts x3

    You get one row that says shirts, with a ×3 badge.

    This works in the quick field. In the New Item sheet, use the Quantity stepper; there, "3 shirts" is just a name.

    Two things to know before you rely on it:

    The number only shows on physical items. Prep, Return and Plans create new entries as to-dos by default, not items — and a to-do never displays a quantity badge. Type "3 phone chargers" on the Return tab and you'll get a row reading "phone chargers" with no ×3 anywhere. The 3 was stored; it just isn't shown. If you need the number visible there, open the row's editor and change its type to Item.

    A leading number breaks the search. "3 phone chargers" is matched against the library including the "3", so it finds nothing and offers to create a duplicate custom item. Type the name first, pick the library match, then adjust the number on the row.

    Go deeper

    Drag the + to place the item exactly

    Instead of tapping the +, press and drag it. A line follows your finger through the list showing exactly where the item will land — including whether it's going inside a group or below it, which the line's indent tells you. Release, and the add field opens right there, already targeted.

    This is the fast way to put something in the right group without adding it and then moving it.

    Get it into your library so it's there next time

    A Create "…" item exists only in this trip. It will not be suggested on the next one, until you put it in your library:

    • Press and hold the row → Save to Item Library. The menu offers it only on a row that isn't a library item already.
    • Or open the row's editor → Add to Item Library. If you've changed anything in the editor, the button says Save & Add to Library and does both.
    • Or save the trip as a template. ••• → Save as Template. Every item in a template is a library item, so the trip's one-offs join your Item Library when the template is saved, unless you chose to leave a section's items out of it. See Templates.
    • Or add it in the library directly. Settings → Item Library → +, and type it in there. See The Item Library.

    Make a whole new section

    If you're adding six related things, they probably want a section of their own. Manage Sections → Custom Section (top right of the list). See Make the list shorter.

    Add rows live at the bottom of every section too

    Every section has its own + Add Item row at the foot of its list. Tapping it opens the quick field, already targeted at that section, so you skip choosing one.

    If something looks wrong

    The + isn't there. Two reasons: you're on a completed trip (which is read-only — reopen it from the ••• menu if you're within three days of the return date), or the keyboard is already up.

    The item went into the wrong section. Open its editor and change the Section there. Rows on a packing list can't be dragged from one section to another.

    I typed something and it vanished. In the quick field, only return, a suggestion or the top row adds. Tapping the ✕ or anywhere else closes the field and drops what you typed. Retype it — nothing is recoverable.

    It added a second copy of something I already have. You typed a leading number, so the search missed the library match — see above. Delete one of them.
